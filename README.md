# Jannis-Lessons

Учебни HTML & CSS материали и уроци.

## Съдържание

- `lesson-1.skeleton.html` – основна HTML структура (скелет)
- `lesson-2.text.html` – текстови елементи
- `lesson-3-links.html` – линкове
- `BMW.html` – примерна страница (упражнение)
- `style.css` – общи стилове за всички уроци

## Как да отвориш

Отвори който и да е `.html` файл директно в браузър, или стартирай локален сървър:

```bash
npx serve .
```
